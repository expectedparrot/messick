Analysis methods

Burden combines reading, comprehension, recall, judgment, response-entry, and conditional overhead components under versioned assumptions. These are estimates, not observed human durations.

Scale output includes item summaries, Pearson inter-item correlations, corrected item-total correlations, Cronbach alpha, alpha if deleted, a one-component exploratory loading diagnostic, and an approximate one-factor omega. Thresholds are warnings, never automatic item decisions.
