CLI workflows

messick init --title TITLE
messick instrument import --survey Survey.ep
messick intent add --input intent.json
messick inspect
messick burden analyze
messick pretest plan --mode cognitive --agents AgentList.ep --models ModelList.ep
messick job generate --plan PLAN --output edsl_jobs/pretest.ep
ep inspect edsl_jobs/pretest.ep
ep jobs cost edsl_jobs/pretest.ep
ep run edsl_jobs/pretest.ep --output data/results/pretest.ep
messick results ingest --plan PLAN --results data/results/pretest.ep
messick pretest analyze --source SOURCE
messick validation evaluate --intent INTENT
messick validate --strict
messick report context
messick report template

--models is required and must use the current ep-agent model selection. Omitting --agents selects the documented bounded respondent pilot of three varied profiles. Plans and generated jobs report questions × scenarios × agents × models as the effective call count.

Simulation-only evidence receives a provisional status after material findings are adjudicated; it does not establish authentic human responses or field readiness.
