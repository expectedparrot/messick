Messick

Agent-first pretesting and claim-specific validation for EDSL Survey instruments.

Concepts · CLI · Agents · Methods · Troubleshooting · Schemas

Concepts

An instrument has immutable revisions. An intent declares a construct, score interpretation, population, use, evidence tier, and tolerances. Issues connect evidence to auditable decisions.

CLI

messick init --title TITLE
messick instrument import --survey Survey.ep
messick intent add --input intent.json
messick validate --strict
messick report context

All successful and failed commands use the JSON envelope defined in the specification. Run any command with --help for its exact options.

Agent integration

messick agent next returns one deterministic recommended action with its working directory, argument array, mutation and approval flags, reason, and—when needed—an input schema.

Evidence boundaries

Simulated responses are pretesting evidence, not observations of human measurement. Humanize fielding is optional and external. Paid inference is performed by ep, never Messick.
